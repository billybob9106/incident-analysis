# Incident Analysis Learning Project

A Python/Jupyter data analysis project using mock IT incident data.
This project demonstrates an end-to-end analysis workflow: data generation,
exploration, control mapping, risk scoring, theme analysis, and reporting.

## Project Goals

- Practice working with realistic tabular data (incidents, RIs, controls, mappings)
- Understand how IT security controls map to remediation work
- Build reusable Python helper functions shared across notebooks
- Produce charts, a markdown report, and an Excel export

## Quick Start

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Generate mock data
```bash
python scripts/generate_data.py
```

### 3. Run notebooks in order
```bash
jupyter notebook
```
Open and run notebooks 01 through 05 in sequence.

## Data Description

| File | Description |
|------|-------------|
| `incidents.csv` | 150 mock IT incident tickets (Systems, Technology, Hardware) |
| `ris.csv` | ~300 remediation items linked to incidents |
| `controls.csv` | 30 invented IT/security controls across 8 domains |
| `mappings.csv` | Many-to-many control→RI mappings with intentional gaps |

---

## Notebooks

| Notebook | Purpose |
|----------|---------|
| `01_explore_data` | Load datasets, inspect shape/types, distribution charts |
| `02_control_mapping` | Identify control coverage gaps and over-represented controls |
| `03_team_risk` | Score and rank all 20 teams by composite risk |
| `04_themes` | Word frequency analysis across incident and RI text |
| `05_summary_report` | Generate `REPORT.md` and Excel export |

## Reproducibility

Random seed is fixed at `42` in `generate_data.py`. Running the generator
twice produces identical output.
